# Alert Emails Directory

This folder stores alert emails generated by the Smart Health Monitoring IoT System.

## Purpose
Instead of sending emails via SMTP (which requires email server configuration), all alert emails are saved as HTML files in this directory with the following naming convention:

```
YYYYMMDD_HHMMSS_patient-id_ALERT_TYPE.html
```

### Example:
- `20260613_094356_patient-1_FALL_DETECTED.html`
- `20260613_094357_patient-2_EMERGENCY_HEALTH_ALERT.html`

## File Format
Each file contains a fully-rendered HTML email with:
- Alert summary (type, severity, patient ID, timestamp)
- Vital signs table (Heart Rate, SpO2, Temperature, Blood Pressure, etc.)
- AI predictions (Status, Risk Score, Anomaly Detection, Heart Rate Forecast)
- Patient profile information
- Link to dashboard

## Viewing Emails
1. Open any `.html` file with a web browser to view the formatted email
2. Emails are grouped by timestamp and patient ID for easy tracking
3. You can keep/archive emails by moving them to another folder

## Re-enabling SMTP
To send emails via SMTP instead of saving to files:
1. Create a `.env` file with proper SMTP credentials
2. Set: `ALERT_SMTP_USER`, `ALERT_SMTP_PASSWORD`, `ALERT_SMTP_HOST`, `ALERT_SMTP_PORT`
3. Restart the containers

The system will then both save files AND send emails via SMTP.
