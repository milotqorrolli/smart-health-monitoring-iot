# Models Directory

This directory stores trained ML model artifacts generated by `python ml/train_models.py`.

## Files Generated After Training

- `status_classifier.pkl` — Patient health status classification model
- `risk_regressor.pkl` — Numeric risk score regression model
- `anomaly_detector.pkl` — Anomaly detection model (IsolationForest)
- `heart_rate_forecaster.pkl` — Heart rate time series forecasting model
- `preprocessing_pipeline.pkl` — scikit-learn preprocessing pipeline
- `feature_schema.json` — Ordered feature names expected by models
- `model_metadata.json` — Model versions, training dates, dataset sources
- `model_metrics.json` — Evaluation metrics for all models

## How to Generate

```bash
pip install pandas numpy scikit-learn joblib openpyxl pyyaml
python ml/train_models.py
```

The `.pkl` and `model_metrics.json` files are in `.gitignore`.
`feature_schema.json` and `model_metadata.json` are tracked for reference.
